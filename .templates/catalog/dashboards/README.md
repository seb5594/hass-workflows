{{BADGES}}

Lovelace cards and themes for Home Assistant, installable through HACS or, from Home Assistant 2026.11,
the built-in Marketplace. Each project lives in its own repository; this catalog lists the public ones
with their version, test results and release downloads.

## Install

Use the *HACS · Marketplace* badge in that project's README. It opens the repository in your instance.

To add it by hand, add the repository as a **custom repository** with the category **Dashboard**:
**HACS → ⋮ → Custom repositories** on 2026.10 and older, **Settings → Marketplace** on 2026.11 and
newer. Download it and reload the browser. A card then appears in the card picker of the dashboard
editor, a theme in your profile settings.
