results and release downloads.

## Install

Use the *HACS · Marketplace* badge in that integration's README. It opens the repository in your
instance, in HACS on Home Assistant 2026.10 and older and in the Marketplace on 2026.11 and newer.

To add it by hand, add the repository as a **custom repository** with the category **Integration**:
**HACS → ⋮ → Custom repositories** on 2026.10 and older, **Settings → Marketplace** on 2026.11 and
newer (a GitHub account is required for custom repositories). Download it, restart Home Assistant and
add the integration under **Settings → Devices & services**.
